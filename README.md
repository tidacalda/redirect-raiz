# redirect-raiz
Redireciona dacalda.com.br (sem www) para https://www.dacalda.com.br.
O site oficial fica no Cloudflare Pages (projeto dacalda-site). Este repositório contém só a página de redirecionamento.
- index.html: raiz. 404.html: qualquer outro caminho (preserva o caminho: /contato -> www.dacalda.com.br/contato).
- CNAME: domínio personalizado do GitHub Pages.
